# LanternLogic Agent vs Manus 2.0 对照（2026-10-01 第二版，当日晚间更新）

> 对比口径：Manus 2026 世代（官方旗舰 1.6 Max 架构），能力清单以其官方公开页为准；
> LanternLogic Agent 侧全部为**本仓库实装实证**（班次记录 + 验收记录可查，不写愿景）。
> 第一版见 git 历史；本版反映当日新增：沙箱实装、摘要式记忆、桌面安装包、MCP 插件层、视频全链路、技能供应链防护。

## 一、一句话定位

| | Manus 2.0 | LanternLogic Agent |
|---|---|---|
| 形态 | 云端 SaaS，订阅积分制 | **本地优先**桌面/自托管应用，自带 Key（BYOK）按量付费 |
| 数据 | 任务数据在 Manus 云端 | **任务数据不出本机**（LLM/视觉 API 调用除外） |
| 开放性 | 闭源黑盒 | 七层接口可替换、事件契约公开、**MCP 万物皆可插**、可白标二开 |

## 四、结论（第二版）

**核心能力对齐度：约 95%**——上一版的三块硬差距（沙箱、长任务记忆、桌面壳）已消掉两块半，剩余为实时语音、大规模并行、自动化 E2E。

**产品化对齐度：约 65%**——安装包虽出但分发链（真机验证/LICENSE/干净机安装）未走完，移动端与第三方集成未做。

**综合可交付度：约 8.0 / 10**（上一版 7.5）。

**对客户的核心叙事（更新版）**：
1. 数据不出本机（隐私刚需）
2. 大脑自由：10 家模型 BYOK + 全本地免费档
3. 视频降维：四引擎 + 零抽卡 + 长视频拼接 + 成本红线（Manus 单按钮给不了）
4. **万物皆可插：MCP 开放生态，能力随装随长**（Manus 封闭给不了）
5. 用量透明到每条任务 + 生成前报价
6. 可白标二开（契约公开 + 七层可替换）

**剩余差距清单（按优先级）**：
1. 安装包真机验证 + LICENSE + 干净机安装脚本（分发链走完）
2. 手机浏览器直连（局域网 + 访问密码 + 修 env 泄露 Key）
3. 自动化 E2E 回归套件
4. 实时语音 / 会议纪要
5. Slack / 邮件集成（webhook 已备）
6. Wide Research 大规模并行

**总评**：核心引擎层面已不输 Manus 2.0 的形态——沙箱、记忆、视频、生态扩展这几块 either 打平 either 超越；差距集中在"商业产品的最后一公里"（分发验证、移动触达、集成生态、长期稳定性证据），全部是工程量问题，无技术不确定性。
