## 怎么拍的（可复现）

用**仓库自带**的 Playwright（`backend/.venv` 里那个）驱动**系统 Edge** 打开本机运行的
`http://127.0.0.1:8642/?token=<访问令牌>` 真截，**不摆拍** ✓。

脚本：`_临时工具/_shoot_readme.py`（评审目录里，未进仓库）。

三处踩过的坑（脚本里都写了注释 ✓）：
1. **没跑过 `playwright install`** ⇒ 用 `channel="msedge"` 走系统 Edge ✓（省几百 MB 下载）
2. **团队是全屏浮层**，打开后会盖住侧边栏 ⇒ 每张图都要**重新加载**页面再拍 ✓
3. **点开团队默认停在「员工卡」** ⇒ 要再点一次「群聊」、再点群名，才是聊天界面 ✓
   （第一版没点到位 ⇒ 拍出来的图和说明不符 ✗ —— 现在脚本会**拒绝拍名不副实的图** ✓）
