# LanternLogic Agent 用户指南

> 本地运行的 AI 智能体 · 数据不出本机 · 自带 Key（BYOK）

## 一、这是什么

LanternLogic Agent 是一个装在你自己电脑上的 AI 智能体：给它一句话，它能拆计划、调工具、写代码、查资料、做表格、生成图片视频，最后把产物交给你。

- **数据全在本机**：任务记录、知识库、长期记忆都存在你电脑的数据目录里
- **自带 Key（BYOK）**：AI 服务用你自己的账号和密钥，请求从你的电脑直达服务商，不经任何中间服务器
- **危险动作先问你**：删除、越界访问等命令会弹审批；也可以开 Docker 沙箱完全隔离

## 二、安装（Windows）

1. 安装 **Python 3.11+**（[python.org](https://www.python.org/downloads/)，勾选 *Add to PATH*）和 **Node.js 18+**（[nodejs.org](https://nodejs.org/)）
2. 解压安装包，双击 **`install.bat`**——自动创建运行环境（首次约 5-10 分钟）
3. 完成后双击 **`start.bat`**，浏览器打开 `http://127.0.0.1:8642` 即可使用
4. 可选：装 [Docker Desktop](https://www.docker.com/products/docker-desktop/) 开启沙箱模式（命令进一次性容器执行，弄不坏你的电脑）

> 系统要求：Windows 10/11，8GB 内存（沙箱模式建议 16GB），磁盘剩余 10GB+。

## 三、配置 AI Key（5 分钟）

LanternLogic Agent 的"大脑"需要一把你自己的 Key：

1. 到模型服务商官网申请 API Key（推荐入门：**智谱 GLM** 或 **DeepSeek**，有免费额度；**小米 MiMo** 性价比高）
2. 把 Key 写入 Windows 用户环境变量（例如 `DEEPSEEK_API_KEY=sk-xxxx`）：
   `设置 → 系统 → 高级系统设置 → 环境变量 → 用户变量 → 新建`
3. 回到 LanternLogic Agent：**设置 → 模型设置**，选服务商，填 **Key 环境变量名**（不是 Key 本身），保存

> **安全设计**：Key 只存在于你的系统环境变量里，LanternLogic Agent 的配置文件和代码里**永远只有变量名**。想换服务商就换环境变量，数据不动。

多模态服务（可选）：图像/视频生成填通义万相或海螺的 Key；语音识别用小米 MiMo（约 0.5 元/小时）；朗读默认 Edge 免费音色。

## 四、手机/平板直连（局域网）

同一 Wi-Fi 下，手机浏览器也能用：

1. **设置 → 常规**：开启局域网模式（或改 `config.json` 的 `server.host` 为 `0.0.0.0`）并**设置访问密码**（强制要求，否则服务不启动）
2. 重启服务，手机浏览器访问 `http://电脑局域网IP:8642/?token=你的密码`
3. 界面自适应手机屏幕；用完建议关闭局域网模式

## 六、常见问题（FAQ）

**Q：任务一直"运行中"不动？**
超过 10 分钟无事件会自动取消（看门狗）。也可以手动取消后查看事件流定位卡在哪一步。

**Q：审批弹窗在哪里确认？**
任务对话流里会出现「允许一次 / 总是允许 / 拒绝」按钮；"总是允许"只对当前任务生效。

**Q：沙箱模式和审批什么关系？**
沙箱（Docker）开启后 shell 命令进容器执行，免审批；"变更前确认"模式下所有命令都会先问你（沙箱也不例外）。

**Q：换电脑怎么迁移数据？**
拷贝整个数据目录（默认 `backend/data/`）：任务、知识库、团队、记忆都在里面。

**Q：试用期到了会丢数据吗？**
不会。到期后历史任务/产物/导出全部可用，仅创建新任务需要录入 License key。

**Q：语音输入没反应？**
语音识别需要配置小米 MiMo 的 Key（环境变量 `XIAOMI_MIMO_API_KEY`），约 0.5 元/小时。
