## 四、这轮的三个教训（都是我自己踩的）

1. **`tsc` 通过 ≠ UI 能跑**：我把 hooks 写在 early return 之后，整个输入区渲染不出来，而 tsc 一路绿。
   → 改 React 组件**必须真跑页面**并监听 `pageerror`。
2. **"第一次全绿"可能是假绿**：附件上传测试首跑 121 passed、二跑就红 —— 残留状态导致。
   → **测试必须能重复运行**（连跑两次才算通过）。
3. **"写入型"验证会改用户真实配置**：我验证设置保存时把用户的审批清单填坏了（丢了 4 项），已还原。
   → 验证前记原值、验证后立刻还原。
