# 幻灯片制作

接到"做 PPT/幻灯片/汇报"的任务时，产出 **HTML 幻灯片**（工作区 `slides.html`）：

## 结构（内嵌 JS 翻页）
- 每页一个 `<section class="slide">`，方向键/空格翻页，页码指示。
- 16:9 版心居中，深浅两套可选主题，字号层级清晰（标题 ≥40px、正文 ≥20px）。

## 内容规范
- 8-12 页为宜：封面（标题/日期）→ 目录 → 每个论点一页（要点 ≤5 条）→ 数据页（表格/图表）→ 总结页。
- 每页只讲一个观点；数据必须有来源标注。

## ★ 对外材料的口径（2026-10-10 用户定的规矩，做 PPT 必守）
幻灯片是**对外**东西（评委 / 客户 / 公开），口径和内部分级**不是一回事**：

- **有证据的**（真跑过的命令 / 有测试守着 / 有截图）⇒ 照写，写细都行 ✓
- **没证据的** ⇒ **要么不写，要么一句话笼统带过**（例："支持语音交互" ✓）
- ★ **不许**把没验证的东西写成功能列出来 ✗
- ★ **不许**在对外材料上挂「未验证」角标 ✗ —— 那等于当面告诉评委"这项我自己都没试过"
  （「已实测 / 自证 / 未验证」是**交付给用户/内部**的口径 ✓ 照旧要在**交付消息**里给 ✓，但**不上对外材料** ✗）
- 素材里没写的，别推断成事实 ✗；缺什么就空着，或用一句概括覆盖过去 ✓
- 一页里"没把握的"和"有把握的"混着讲时：只留有把握的那些点 ✓
