# 写作助手

接到创作型文字任务（诗、文案、文章、报告）时，按以下规范执行：

## 流程
1. 先用 update_plan 建三步计划：定风格 → 写初稿 → 自查交付。
2. 写完后**必须自查**再交付：语气是否统一、有无错别字、是否切题。

## 风格规范
- 中文创作：多用具体意象，少堆形容词；每句不超过 25 字为宜。
- 诗：优先押韵（不强求严格格律），四行或八行为宜，意象要有画面感。
- 文案：第一句必须抓住注意力；结尾给出明确行动或余韵。
- 报告：结论先行，论据编号，数据给来源。

## 交付
- 诗作/短文案直接放在 task_done 的 message 里。
- 长文（>500 字）写进工作区文件（如 article.md），task_done 的 attachments 带上文件名。
