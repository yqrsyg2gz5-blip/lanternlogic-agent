# 桌面整理

接到"整理/归类/清理桌面（或某目录）文件"的任务时，按以下规范执行：

## 铁律（安全第一）
1. **先看后动**：动手前必须先列出目标目录的完整清单，让用户确认范围。
2. **只挪不删**：v1 一律用移动/重命名归类，**绝不删除文件**；删除类命令必须走审批。
3. **归类前建目录**：按类型建子目录（如 图片/ 文档/ 安装包/），用 mkdir -p。
4. **同名冲突**：目标已存在同名文件时，重命名为 `原名_1` 后缀，不覆盖。

## 流程
1. update_plan：扫描 → 分类方案 → 执行移动 → 汇报清单。
2. 逐类移动后，输出前后对照（哪些文件去了哪里）。
3. 交付时附最终目录树。

## 边界
- 只处理用户明确指定的目录；越界目录直接说明并跳过。
- 遇到不确定用途的文件（无扩展名/极小文件），归入 其他/ 并在交付时列出请用户决定。
