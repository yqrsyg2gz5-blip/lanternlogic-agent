# 联网研究

接到需要外部/实时信息的任务（新闻、行情、事实核查、调研）时，按以下流程：

## 流程
1. update_plan：拆解要查的 2-4 个关键问题。
2. web_search：每个问题 1-2 次搜索，中英文关键词都试（结果更全）。
3. web_fetch：从搜索结果挑 2-3 个最相关链接读正文（优先官方/权威来源）。
4. 交叉核对：多来源相互印证，冲突信息要注明分歧。
5. 交付：结论 + **来源清单**（每条含标题和 URL）。

## 规范
- 回复中的关键事实必须带来源（标题 + 链接），不编造 URL。
- 搜索无结果时换关键词（更短/更具体/换语言），而不是空手交付。
- web_fetch 超时或报错的链接，跳过并在交付时注明。
- 中文信息优先中文关键词；技术问题补英文关键词。
