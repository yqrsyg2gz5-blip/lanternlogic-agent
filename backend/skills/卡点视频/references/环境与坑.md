### 1.1 中文字幕：必须显式 `fontfile= \
**四个构建上 `drawtext` 都会打印 `Fontconfig error: Cannot load default config file`。**（MiniMax 6.1.1 的 `-version` 配置里其实带 `--enable-fontconfig`，但本机**仍打印该错误**——本次复核确认。）

**本次复核复现（真跑，不是推断）**：

```powershell
FF='/d/MiniMax Design/current/resources/ffmpeg/ffmpeg.exe'# 不指定字体
"$FF" -y -f lavfi -i "color=c=black:s=320x120:d=1" \      -vf "drawtext=text='中文测试':fontsize=36:fontcolor=white:x=10:y=10" -frames:v 1 -update 1 no_font.png
# 显式指定字体
"$FF" -y -f lavfi -i "color=c=black:s=320x120:d=1" \      -vf "drawtext=text='中文测试':fontsize=36:fontcolor=white:x=10:y=10:fontfile='C\:/Windows/Fonts/msyhbd.ttc'" \      -frames:v 1 -update 1 with_font.png
```
实测结果：**不带 `fontfile=` → 4 个空豆腐块，PNG 433 字节；带 `fontfile='C\:/Windows/Fonts/msyhbd.ttc'` → 正常「中文测试」，PNG 2781 字节。**

- 中文标题/字幕用 **`C:/Windows/Fonts/msyhbd.ttc`**（微软雅黑粗体，实测可用）。
- 时间码/等宽标注可用 `C:/Windows/Fonts/consola.ttf`。
- **PowerShell 写法注意**：路径里的盘符冒号要转义成 `C\:/...`，并整体用单引号包住，例如 `fontfile='C\:/Windows/Fonts/msyhbd.ttc'`。
- 参考项目 `contact-sheet.sh` 里的注释印证同一件事：*Windows builds of ffmpeg often have no fontconfig, so point at a system font*，以及 *ffmpeg 5+ no longer accepts the escaped drive colon unquoted*。

## 6. 踩坑清单（都是实测或原文明确记录过的）

### 6.1 ffmpeg 相关

1. **`-/filter_complex <文件>` 语法**：参考项目 `build-timeline.mjs` 用它，本机 2019 构建实测 `Unrecognized option '/filter_complex'`。→ **改用 `-filter_complex_script <文件>`**（本次复核：MiniMax 6.1.1 上 `filter_complex_script exit=0`；2019 构建上也实测可用）。
2. **单帧 PNG 要加 `-update 1`**：ffmpeg 6.1.1 下 `-frames:v 1 out.png` 会警告 `The specified filename ... does not contain an image sequence pattern`，加 `-update 1` 消掉（本次复核）。
3. **`ebur128` 的逐帧行也含 `I:`**：直接 `grep 'I:|LRA:|Peak:'` 会刷出几十行逐帧输出。**用行首锚定**：`grep -Pattern '^\s*(I|LRA|Peak|True peak):'`（本次复核通过）。且 `True peak:` 与 `Peak:` 分两行输出，**脚本要抓 `Peak:` 那一行**。
4. **渲染器会重新编码音频并抬高真峰**：参考项目实测渲染器把 true peak 顶到 **0.0 dBFS**。→ 渲染后**把未经改动的 `mix.m4a` 原样 `-c copy` remux 回去**（`-movflags +faststart`）。
5. **小节拼接：第一段必须从 0 s 开始**。若从后面开始，ffmpeg `amix` 会把流重定基准，导致每一段统一位移（参考项目实际发生过 **40 ms 延迟**）。接缝用 **25 ms 交叉淡化**，且**正好结束在目标强拍上**。
6. **`blackdetect` / `freezedetect` 会命中设计内的黑场与 hold**：`freezedetect` 默认阈值 `d=1.0` 会漏掉 35f(=1.17s) 级别的 hold，按需调到 `d=0.5`。**验收目标不是「零命中」，而是「命中清单 == 设计白名单」。**

### 6.2 渲染器 / 画面相关（来自参考项目原文，本机未逐条复现）

1. **超过约 40 个带 `radial-gradient` / `filter: blur()` / `clip-path` 的元素同时在屏 → 出黑帧。** 把纹理（半调点、噪点、涂鸦、做旧）烘成 PNG tile 放 `assets/images/`，用 `background-image` / `mask-image`。
2. **渲染循环里禁用 `getImageData`**（连剖测都不行）：几次 readback 后 Chrome 会把 canvas 从 GPU 挪到 CPU，每次 `drawImage` 慢约 **50×**。
3. **SVG 滤镜（RGB split）只在特效运行时挂上**，几帧后设回 `none`；重全屏层用 `visibility` 切换比 `opacity: 0` 便宜。
4. **单文件超过约 1000 行**时 `lint` 会警告 `composition_file_too_large`，但仍能渲染（两个参考稿是 1332 行和 1636 行）。
5. **多 worker 共享一块 GPU**：参考项目注释——笔记本 iGPU 到 **4–6 worker** 吞吐就不再增长，之后下降。默认 `CPU核数/4` 夹在 1..6。
6. **`librosa` 在 Windows 的 import 可能挂起**——这是参考项目一的**声明**（`librosa is deliberately not used; its import hung on Windows`），**本机未复现**（venv 里其实装了 librosa 1.0.0，但没测过 `import librosa`）。

### 6.3 时间与音频相关

1. **edge-tts 末词后有静音尾巴**：实测生成 11 个词的 mp3，最后一个词在 **5.35 s** 结束，而文件总长 **6.216 s**（ffprobe：mp3 / 24000 Hz / 单声道）——**约 0.87 s 静音尾巴**。**切片段必须按最后一个词的 `e` 裁，不能按文件长度。**
2. **edge-tts 默认不发 `WordBoundary`**：默认参数下中英文 `WordBoundary` 计数都是 **0**，必须显式 `boundary="WordBoundary"`。
3. **对配音变速后，词级时间戳必须同步除以倍率**：clip 内时刻 `x` 映射到时间线要 `place + (x - seg.a) / tempo`，包括每个词的 `s/e`。
4. **静默之后不要有孤立的响亮一击**：*a hit in silence startles. The same hit inside a groove sounds fine.*
5. **不要靠笔记本喇叭判混音**：用干声 + 台词掩码**测量** RMS（见 `卡点与音频.md`）。
