## 1. 一张配方卡的字段结构

原始卡来自 `Vincentwei1021/video-shotcraft`（MIT）：**YAML frontmatter（6 字段）+ 6 个中文小节**。

| 区块 | 字段 | 作用 |
|---|---|---|
| frontmatter | `name` | 全局唯一卡名，Gallery 索引与 `style-key` 都按它校验 |
| frontmatter | `一句话` | **给 agent 选卡用的一句话语义** |
| frontmatter | `适用` | 适用场景 |
| frontmatter | `时长` | **帧级时长预算**，含起止帧 |
| frontmatter | `能量` | **排能量曲线用的标签**（低/中/中高/高） |
| frontmatter | `标签` | 分类，与目录类别对应 |
| 正文 | `## 意图` | 为什么这么设计、这一镜要讲什么 |
| 正文 | `## 动效核心` | 逐条动作分解（含缓动/过冲/相位细节）——**实现主依据** |
| 正文 | `## 参数表` | 三列表：`参数 \| 典型值 \| **调节手感**`——**可直接落到代码的数值** |
| 正文 | `## 声音` | **SFX 钉帧**（有的卡写「★ 声音强依赖」） |
| 正文 | `## 已知坑` | **负样本库**，防止重踩 |
| 正文 | `## 参考实现` | 指向**调校过的源码真相** |

**多式卡**：`beat-cut-moves` / `montage-rhythm-moves` / `trailer-grammar-moves` / `panel-grid-moves` 这类「一式多款」的卡，用 **`## 两式选型` / `## 三式选型` 表**（`式 | 做法 | 适用`），参数表按 A/B/C 分列。

### 1.1 落地到 HTML/Canvas/GSAP 的 12 字段（**本方案新增的落地字段，推断，非读到**）

原卡的 `参考实现` 指向 TSX（Remotion）；本产线是 HTML/Canvas/GSAP + Playwright，所以改写为实现中立的 12 字段：

```yaml
id:            # 全局唯一，供索引/引用
name_zh:       # 中文名，人读
energy:        # 低/中/中高/高  ← 排能量曲线
duration_f:    # 目标帧数 @30fps（含起止）
duration_s:    # 秒
适用:          # 什么时候用
intent:        # 这一镜要讲的一件事
motion:        # 动效分解（分步骤，含缓动/过冲/相位）
params:        # 参数表：名 | 典型值 | 调节手感
text:          # 文字处理规则（字号/入场/逗留/退场）
sfx:           # 声音：词汇 + 相对钉帧
transition_out:# 出镜转场方式
known_pitfalls:# 已知坑（负样本）
accept_frames: # 2 个验收帧号（实现完必须截图自检的帧）
```

`text` 与 `transition_out` 是**本方案补充的字段（推断）**，因为本产线要模型自己写文字动画与转场；原卡把文字规则散在「动效核心」里。

### 1.2 用卡的硬规则（**读到原文**）

> 「用镜头卡动效必须先解析 Gallery 索引并读准确的 demo 实现代码……配方卡给的是语义和参数表，准确的 demo 源码才是调校过的参数真相（缓动、时值配比、摘罩时机、已知坑的规避写法）。**凭卡名和理解新写＝放弃全部调校积累。**」

- 卡上「已知坑/命门」标注的参数**不得降档**，「质量标准只升不降」。
- **一种动画手法全片只当一次主角**。
- 段落级节奏偏好是**单向的**：「**历史反馈全部指向『放慢/停留』，从未有一次『太慢了』**」——这是最该抄进系统提示的一条。

### 1.3 卡名与「卡名 · style 名」定位符

- 157 张卡 / **214 个 style 键**（原始卡库口径；仓库 GitHub 描述页写 152/209，**仓库自身三处不一致，照抄并标注，不替它圆**）。
- **派活给模型时写 `beat-cut-moves · beat-cut-accelerando`**，不是只写卡名。
- ⚠️ 一处已知差异：`speed-ramp-freeze` 的 style 键是 **`speed-ramp`**，而卡内 demo 文件叫 `SpeedRampReal.tsx`——**以 `styles` 键为准**。

### 卡 01 · `brand-ink-open` ｜墨染开场（品牌开幕）〰️

- **能量**：低 ｜ **时长**：3.5s（105f）｜ **适用**：全片第一镜；品牌字标或产品名入场
- **意图**：开场只讲一件事——「这是什么」。用一笔墨/一层遮罩的扩散把品牌推出，而不是淡入一张 logo。
- **motion**
  1. 起手 8f 纯底色静止（给「片子在播」的可感起点）
  2. 45f 墨/遮罩从画面一侧连续扩散铺满（**连续生长，不许分段跳变**）
  3. 字标随后 25f 内从遮罩里显影
  4. 终态真静止 ≥27f，让观众把品牌读一次
- **params（〰️ 推断：原卡正文未读到，按同类判例改写）**

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 扩散时长 | 45f | <30f 读不出「生长」，>60f 拖 |
| 扩散路径 | 单一方向连续 | 分段/跳变即被读穿 |
| 终态静止 | ≥27f | 品牌字标落定后必须呼吸 |

- **text**：字标为画面**唯一**动作主体；字号占画面高 ≥12%；不加任何装饰性 glint
- **sfx**：`whoosh`（扩散起）+ `sparkle`（字标显影）
- **transition_out**：硬切到卡 02（同色系，视觉连续）
- **known_pitfalls**：开场贪多——多元素群舞撑不起第一印象；装饰性光效群发即廉价
- **accept_frames**：f45（扩散中段）、f105（终态）
- **出处**：`references/shots/opening/brand-ink-open.md`（**文件存在，正文未读到**）；时长与「开场单主角」判例来自 `aesthetic-rules.md` Q5 / `pipeline.md` 阶段 3（**二手转述**）

### 卡 02 · `letterspace-materialize` ｜大字距字标结晶 ✅

- **能量**：低 ｜ **时长**：3.2s（96f）= 静置 15f + 描画 50f + 终态 ≥30f ｜ **适用**：片尾/片头品牌字标、章节题字
- **意图**：字标不是淡入也不是打字机，而是「结晶」——全部字母**同帧起笔**、笔画像手写一样**连续生长**、**同帧齐收**成词。
- **motion**
  1. 骨架笔画 SVG path（单线条字形），`pathLength` 归一化
  2. 全字符共享**同一进度 p**：`strokeDashoffset` 1→0 连续描画
  3. 曲线整体 ease-in-out，中段略快首尾略缓（起笔收笔手感）
  4. 全部字母同帧完成 → 终态静置 ≥30f
- **params（✅ 读到原文数值）**

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 描画时长 | ~50f（f16 起 f68 收 @30fps） | <30f 读不出「画」的过程；>80f 拖 |
| 同步性 | 全字符同帧起收、**零错峰** | 判例：逐字错峰版被裁「所有字母是在同一个时间完成书写」 |
| 连续性 | pathLength 连续生长、无分段跳变 | 判例：遮罩分段版被裁「应该是连续的笔画画出来」 |
| 字形 | 骨架单线、字面宽高比 ~1.07、笔画细 | 竖长（比 <0.8）被裁；粗笔画丢结晶感 |
| 字距 | ~0.6em | 大字距是本卡身份；<0.3em 改用普通描画 |
| 终态静置 | ≥30f | 完成后必须让观众读一次整词 |

- **text**：字标即主体；底景只能是氛围渐变/空镜，**字标是画面唯一动作**
- **sfx**：`riser`（起笔前）或全程静音（静谧仪式感更强）
- **transition_out**：静止收尾后硬切
- **known_pitfalls**：① 骨架字形需手绘 path——**现成字体轮廓是双线勾边，描画观感完全不同**；9 字形工作量 ≈1h，实战优先复用字形库 ② 与「通用描画」卡分工：本卡命门是**整词同步**
- **accept_frames**：f40（描画中段，任一中间帧都该像「写到一半」）、f96（终态）
- **出处**：<https://github.com/Vincentwei1021/video-shotcraft/blob/main/references/shots/opening/letterspace-materialize.md>（**全文读到**）

### 卡 03 · `spotlight-hero-card` ｜聚光灯锁定主角卡 ✅

- **能量**：中（**质感最高的一镜，节奏慢而稳**）｜ **时长**：4.6s（82–220f = 138f）｜ **适用**：产品宣传片开场；把一个核心对象（卡片/条目/模块）立成全片主角
- **意图**：开场只讲一件事——这一张卡就是产品的原子单位。聚光灯替观众做视线引导，弹起悬浮给它体积和重量，轮廓光束是「扫描/检视」的隐喻，贴回原位表示它属于这个页面。
- **motion**
  1. 游走聚光灯经**4 个中间站**后锁定卡心，光池收拢 + 锁定瞬间脉冲，外部 vignette 压暗
  2. 相机从全页正视推进到斜侧特写（**左侧机位主导**），焦点略偏让卡落在画面偏右
  3. 卡片 rise（带过冲）→ 悬停 sin bob → reseat（落地微压）
  4. SVG rounded-rect 轮廓光束跑两圈：第一圈快而亮、第二圈慢而弱
  5. 卡起飞后原位铺页面底色补丁 + 强调色呼吸描边，落地瞬间增亮消失
- **params（✅ 读到原文数值）**

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 选卡 | cards[3]，中心 x 恰为 960（页面中心） | 主角卡按「推进后构图居中」选，不是随便挑 |
| 相机 | 静止全页 zoom 0.78（82–114f）→ 16f 推进 zoom 2.6；rotY 34° 主导 + rotX 仅 8°，persp 1200 | 侧向水平机位读感优于俯拍；收尾禁用尾漂，呼吸必须是真静止 |
| 聚光灯 | 4 个中间站（86→130f），光池半径 620→420→360 收拢，锁定 +6% 脉冲；vignette 0.16→0.42 | 中间站让「随机照射」可信；直奔目标读作程序化 |
| 动作弧 | rise 10f（`bezier(0.2,1.25,0.3,1)` 过冲）→ 悬停 54f（sin bob 振幅 4px 周期 40f）→ reseat 18f，落地 press 0.997 | 锁定→落地 ≈98f≈3.3s——**质感镜头要「放慢到 3 秒」，初版几乎总是偏快** |
| 轮廓光束 | lap1 142→156f（strokeWidth 5+2.5 双层）、lap2 162→182f（3.5+1.75、opacity 0.62） | 两圈快慢有别才读作「持续扫描」，**一圈是眨眼**；光束只给主角一次 |
| 双层影 | `0 8·lift px …, 0 46·lift px 90·lift px` 随高度生长 | **影子不随高度长，悬浮就不成立** |

- **text**：卡上文字在推进特写下会糊，**根因是纹理栅格化分辨率不是景深**（判例 Q2）
- **sfx**（✅ 读到）：弹起钉 `whoosh-big`（f127）、光束扫描钉 `sparkle`（f141）、reseat 钉 `transition-snap`（f204）——弹起/光效/落定**各有专属音**
- **transition_out**：贴回原位后真静止 ≥15f（cx/cy/zoom/rot 全锁死）
- **known_pitfalls**：① 开场多卡群舞撑不起第一印象 ② 逐卡 glint 闪烁被两次否决——「不需要每个卡片都闪烁一下」，光效严格只给主角
- **accept_frames**：f138（悬停中段）、f204（reseat 落定）
- **出处**：<https://github.com/Vincentwei1021/video-shotcraft/blob/main/references/shots/opening/spotlight-hero-card.md>（**全文读到**）

### 卡 04 · `text-as-mask` ｜文字当遮罩 〰️

- **能量**：中 ｜ **时长**：3.0s（90f）｜ **适用**：把一句核心 tagline 变成「看穿」产品的窗口；知识科普的章节过渡
- **意图**：文字不做动效，文字**就是取景框**——透过字缝看到产品画面，文字本身静止，画面在字后运动。
- **motion**
  1. 黑/底色铺满，巨型文字以底色呈现在最上层（字的内部透明、外部遮住画面）
  2. 底层画面缓慢平移/推近（2.5D 微动，速度恒定，**不可静止**——静止就退化成一张图）
  3. 收尾 12f 文字遮罩整体放大到字缝出血，画面全亮
- **params（〰️ 推断：原卡正文未读到，按同类判例改写）**

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 文字占高 | ≥45% 画面高 | 太小读不出「穿透」，退化成字幕 |
| 底层运动 | 恒定慢速推近 1.0→1.06 / 全程 | 静止即失效；速度快于推镜会晃眼 |
| 出血放大 | 末段 12f，放大 ≥3x | 让字框边缘滑出画外，不能残留 |
| 停留 | 至少 30f 让句子读完 | 文字是信息载体，快过阅读速度即无效 |

- **text**：**同一时刻只能有一句**；字号按「观众念得完」定，不按 font-size
- **sfx**：`whoosh`（出血放大）+ `riser`（如有后接高潮）
- **transition_out**：出血放大后硬切
- **known_pitfalls**：文字只当装饰、可读性不足即返工；一句话没读完就切
- **accept_frames**：f40（字框内画面运动中段）、f90（出血完成）
- **出处**：`references/shots/opening/text-as-mask.md`（**文件存在，正文未读到**；`params` 全列为推断）

### 卡 05 · `crane-rise-reveal` ｜摇臂升起揭示 〰️

- **能量**：中 ｜ **时长**：4.0s（120f）｜ **适用**：从局部升到全局（一个功能 → 整个产品/工作台）；知识科普的「全貌」镜
- **意图**：不做剪辑上的「切到全景」，而是**镜头本身升起来**，把局部与全局的关系一次讲清。
- **motion**
  1. 起手：局部特写（zoom ≈2.4）停在功能细节上 20f
  2. 主段 60f：相机沿弧线上升 + 拉远，同时轻微 rotX 由 +6° 收到 0°（**不是纯 zoom out**，要有高度变化）
  3. 落定 40f：全景真静止，所有元素归位（**元素必须落进真实布局槽位，不许悬空**）
- **params（〰️ 推断）**

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 起手停顿 | 20f 静止 | 不给停顿，升起就没有参照物 |
| 升起时长 | 60f，曲线 ease-in-out | 线性升起读作机械缩放 |
| 终点 | 全景 scale 1.0，rotX=0 | 终点必须正视为准，留倾斜即「没落定」 |
| 落定静止 | ≥40f | 全景需要阅读时间 |

- **text**：升程中文字**不参与运动**（跟随相机层）；落定后可浮现 1 行说明
- **sfx**：`whoosh`（升起）+ `transition-snap`（落定）
- **transition_out**：静止后硬切或柔叠
- **known_pitfalls**：飞入/升起动画终点悬空（**元素必须落进真实槽位**）；线性缩放冒充运镜
- **accept_frames**：f60（升程中段）、f120（全景落定）
- **出处**：`references/shots/opening/crane-rise-reveal.md`（**文件存在，正文未读到**；`params` 为推断，与读到卡 03「侧向机位优于俯拍」判例一致）

### 卡 06 · `beat-cut-moves` ｜硬切当节拍乐器 ✅

**两式：A `beat-cut-accelerando` 递进硬切串 / B `paparazzi-flash` 连闪定格**

- **能量**：高 ｜ **时长**：A ~4.3s（建立 49f + 五连切 + 定格 hold 35f）；B ~4.3s（活素材 30f + 三闪 + hold 60f）
- **适用**：高光/冲刺段落把「切」本身打成鼓点
- **意图**（✅ 原文）：库内节奏词汇只管「一条运动内」的速率和「落定后停多久」，没有词管**多镜之间切点怎么排**。本卡补这一块：**硬切不做任何过渡，切点间隔本身就是乐谱**——间隔递减读作加速逼近（A），等距三闪读作快门连拍（B）。
- **选型（✅ 读到原文表）**

| 式 | 做法 | 适用 |
|---|---|---|
| A `beat-cut-accelerando` | 六视图按 **16→12→8→6→4f** 间隔减半全屏硬切，加速逼近，末刀戛然定格回主画面轻推收住 | 冲刺逼近感：预告片式蓄力、功能连打冲向结论 |
| B `paparazzi-flash` | 三次白闪各硬切**同素材不同裁切**（全景→卡片特写→数字特写），快门余韵沉降，第三闪停在数字收束 | 高光时刻仪式感：颁奖连拍、关键数字的加冕 |

- **params（✅ 读到原文数值）**

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| A 切点帧 | 0/49/65/77/85/91/95（建立 49f，间隔 16→12→8→6→4f） | 间隔按「减半律」缩，**等差缩读不出加速**；末间隔 <4f 肉眼跟不上 |
| A 视图池 | 6 个 = 两块 FakeDashboard × scale 1/1.8/2.6 + 对焦点 | 视图必须是**同一产品的不同构图**（语义连续），六个无关画面读作故障 |
| A 切帧快门感 | 切帧 1f brightness 1.05 + 叠 6% 白层 | 只在切帧亮一下，是「咔」不是闪光灯；再厚就抢了 B 式的活 |

## 3. 节奏编排规则

### 3.1 段位表（`references/sequences/promo-energy-arc.md`，**全文读到**）

适用于 **30–60s 多功能 web 产品宣传片**（4 段位 + 2–4 张字卡）：

| 段位 | 时长占比 | 能量 | 职责 | 首选镜头卡 |
|---|---|---|---|---|
| ① 品牌开场 | **8–12%**（30s 片）；开场+立传合计可达 **20%** | 低 | 字标落定 + hold ≤1s（R1）；产品页面 | `brand-ink-open` |
| ② 单主角立传 | **12–15%** | 中（**质感最高、节奏最慢**） | 一个主角、一条完整动作弧 ≤3s（Q5/R3） | `spotlight-hero-card` |
| ③ 功能升级段 | **55–65%** | 中高±低交替 | 每镜只给一个新功能、一种手法只当一次主角（P4） | `deck-deal-flyin` / `type-and-filter` / `list-stack-press` / `row-embed` / `document-typewriter-reveal`（**卡名经画廊索引校验存在；卡正文未读到**） |
| ④ 发布/峰值收尾 | **13–16%** | **峰值（全片最高）** | 已展示功能各出代表元素合影驻足字标（Q8），sign-off hold ≤1s（R1） | `outro-group-photo-launch`（**卡名读到，正文未读到**） |

**关键约束（读到）**
- **字卡规则**：每 1–2 个功能镜后插一张，单张 **50–55f（约 1.8s）**，全片 **2–4 张**；密度按功能镜数比。
- **段位比例是单例实证**（标注：单例判例）：15s 短片或单功能产品应大胆合并段位，**但 ①hold / ④峰值两端不可省**。
- **每镜预算**：**先扣 `hold/rest` 帧**，**再排动效——不是排完动作再找空隙**。
- **填坑 5 步**：① 列功能清单 → ② 按段位分配总帧数 → ③ ②段能量妥协：高能量帧与**舒缓帧间隔排列** → ④ 逐格扫 frontmatter 挑卡 → ⑤ 镜头排定后逐接缝选转场。
- **字卡 / outro 文案重复即删**（P4 判例：outro tagline 去重）。

### 3.2 三条「不许违反」的节奏铁律（读到，原文判例）

1. **R1 · 关键信息落定后必须呼吸**：判例含「**品牌字标 hold ≤1s**」「**sign-off hold ≤1s**」；`pipeline.md` 阶段 3 另给正向预算「品牌字标落定 **hold ≥1s（30f）**、批量动效收尾 **0.5s 静止**、开场主体动作 **≥3s**」。
   ⚠️ **两说并存**：`pipeline.md` 给的是 **≥1s** 的正向预算，`aesthetic-rules` R1 给的是 **≤1s** 的上限判例。**两条都要满足 ⇒ 品牌字标 hold 就是约 1 s（30f），不是越长越好。** 另：结尾禁尾漂，**呼吸必须是真静止**。
2. **R3 · 开场主体动作 ≥3s**；「开局默认放慢一条，主体动作在 ≤3s，交接演示按真实人操作速度」；**宁慢勿快**。
3. **R4 · 整画面级节拍冲击全片 ≤3 处，相邻 ≥16 拍**；其余拍点动效只动**元素层**；「节奏偏好单向：过快必返工、放慢从未被否」。

### 3.3 BPM → 切镜密度

**读到的实测基线**：一支 **70s、18 镜、131.97 BPM** 的电子鼓点宣传片，**渲后回测全部切点误差 ≤2.2f**（感知阈值约 3f）。`T = 60/BPM` → 131.97 BPM ≈ **0.4547s ≈ 13.64f @30fps**。

**下表为推断（基于上述基线换算，原文未给这张表）**：

| 音乐性格 | BPM 区间 | 1 拍时长 @30fps | **每镜占拍数** | 平均镜长 | 30s 片镜头数 |
|---|---|---|---|---|---|
| 慢/抒情/高端质感 | 60–90 | 33.3–20f | 8 拍 | 4.4–8.9s | 4–7 |
| 中速/叙述/科普 | 90–110 | 20–16.4f | 4 拍 | 2.7–3.6s | 8–11 |
| **标准宣传片** | **120–135** | **15–13.3f** | **4 拍** | **2.0–2.7s** | **12–15** |
| 快/高能/动作 | 135–160 | 13.3–11.3f | 2 拍 | 1.1–1.8s | 17–27 |
| 冲刺/混剪高潮段 | 160+ | <11.3f | 1–2 拍 | 0.6–1.1s | 段内密集、非全片 |

> ⚠️ **口径冲突（照抄）**：读到的基线 131.97 BPM / 18 镜 / 70s → **平均每镜 3.89s ≈ 8.5 拍**，与上表「标准宣传片 4 拍」不同。原因：该片含长 hold（开场品牌 hold ≥1s、outro 峰值段），不是每镜都短。**所以真正的规则不是「每 N 拍切一刀」，而是「切点必须落在拍上，且每次切之间要留呼吸」**——对应 `beat-sync` skill 的原文禁令：**「Do not cut on every beat automatically. Music needs breathing room.」**

**读到的硬规则（可直接执行）**
1. **镜头边界全部锚到拍号**；时间线用 `beatF(n)` 写，不写裸帧号。
2. **稀疏重音钉真实瞬态而非网格插值点**：**乐谱在 BGM 的强拍上，不在等间隔网格上**。
3. **强/弱拍分级**：根据**节拍强度分配镜头时长**——强拍配重镜/短镜。
4. **渲后回测**：对 2–3 个尖锐 SFX 原文件做归一化交叉相关，误差 **≤3f** 才算过。
5. **两项偏移必补**：`Sequence.from = 目标峰值帧 − 音源峰值滞后帧 − 输出音轨偏移帧`。实测该片 click 滞后 **2032 samples**、impact **2066 samples**（≈1.27–1.29f @30fps）；旧管线出现过 **4f（≈133ms）**。**不补偏移时，最重一击晚了 0.27s，读作音画不同步。**

### 3.4 开场 / 高潮 / 收尾的时长建议

- **开场（推断，综合读到值）**：30s 片 → 品牌开场 **2.4–3.6s** + 主角立传 **3.6–4.5s** = 前 6–8s 完成「这是什么 + 它长什么样」。
- **高潮（峰值段）**：全片**只有 2–3 处大 slam**（R4：整画面级冲击 ≤3 处、相邻 ≥16 拍）；高潮前黑场 **12f 完全无物**；高潮收束 `smash-cut` 一帧硬切进真静止，**死寂段 ≥90f**；峰值段收束句式 = 「riser（组装段起）→ 约 35f 后 impact（主体落地，**全片音量峰值**）→ 25f 后 sparkle（余韵）」，**全片峰值只能有一个**。
- **收尾**：段位占比 **13–16%**；**必须有 ≥40f 真静止**；**终渲交付两版：带 BGM 版 + 无 BGM 版（保留 SFX）**。
- **情绪曲线建模（推断）**：不要做连续曲线，做**段位阶梯**：

```
energy(t) = 段位表[段i].能量      (段i 内的所有镜头继承该能量)
镜头时长 ∝ 1 / energy             (高能段短镜、低能段长镜)
slam 配额: 全片 3 处，必须落在最强 hit 拍上，相邻间隔 ≥16 拍
```

理由：读到的两个仓库都是**离散段位 + 强弱拍分级**，没有一处用连续函数；而 R4 的「≤3 处」「≥16 拍」是**可枚举检查的硬约束**，连续曲线反而无法验收。
