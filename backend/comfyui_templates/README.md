# ComfyUI 视频工作流模板

本目录放 **API 格式**的工作流 JSON，`ComfyUIVideoEngine` 按模板出片。

## 怎么做一个模板

1. 打开 ComfyUI，搭好你的文生视频工作流（例如 H3 / Wan / LTX 节点图），**先跑通一次**
2. 设置（齿轮）→ 开启 **开发者模式 (Dev Mode)**
3. 点 **Save (API Format)** 导出 JSON（这是给程序用的精简格式，不是界面格式）
4. 把文件放进本目录，命名建议 `txt2vid_video_xxx.json`（名字带 `video` 会被优先选用）
5. 用文本编辑器打开，找到**正向提示词**对应的文本，把内容改成：`{{prompt}}`
6. 分辨率/帧数/采样步数等参数直接在 JSON 里设好（API 格式的数值字段放不了占位符）

之后 Agent 调 `video_gen`（engine=comfyui）就会按这个工作流出片，产物自动进任务工作区。

## 本机装了两份模板（★ 名字里带 `video` 的那份 = 默认用的）

| 文件 | 用什么模型 | 档位（烧在 JSON 里） | 实测（2026-10-10） |
|---|---|---|---|
| **`txt2vid_video_h3.json`（默认）** | MiniMax **H3** Turbo（`minimax_h3_fl2va_pruned_int8_convrot`）+ qwen3vl 文本编码器 | 864×480 × 124 帧 ≈ 5.2 秒 @24fps，**带音频轨** | **336 秒** ✓ 产物 h264 + aac ✓ |
| `alt_t2v_wan21.json`（备选） | Wan 2.1 14B（`wan2.1_14B_SCAIL_2_int8`） | 640×368 × 81 帧 ≈ 5 秒，无音频 | 438 秒 ✓ |

★ 引擎的挑法：**名字里带 `video` 的优先**；两份都带就报"有多个视频模板，请留一个"⇒
想让 Wan 当默认，把 `video` 挪到它文件名里、从 H3 那份拿掉即可 ✓

### 档位参考（同一台机器：RTX 5070 Ti Laptop 12GB）

| 档位 | 用时 |
|---|---|
| Wan 480×272 × 33 帧（≈2 秒） | **90 秒** ✓ |
| **H3 864×480 × 124 帧（≈5 秒，带音频）** | **336 秒** ✓ ← 当前默认 |
| Wan 640×368 × 81 帧（≈5 秒） | 438 秒 ✓ |
| Wan 832×480 × 81 帧（≈5 秒） | **30 分钟还没跑完** ✗（会被超时误杀） |

⇒ 想再提高分辨率/时长，把 `video.timeout_seconds` 一起调大（本地引擎会跟随这个配置 ✓）。

## 规则

- 只支持一个占位符 `{{prompt}}`（正向提示词）；负向提示词直接写在模板里
- 多个模板并存时引擎会报错让你二选一——留一个 `video` 模板即可
- 工作流必须**在 ComfyUI 里手动跑通过一次**再导出（节点缺依赖时提交会被拒）
